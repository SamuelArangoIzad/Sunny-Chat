# Sunny-Chat

Sunny-Chat is a modern real-time messaging application built with Flutter, FastAPI, PostgreSQL and Firebase Cloud Messaging (FCM).

The project implements secure JWT authentication, persistent conversations, realtime chat updates, push notifications, profile photo uploads and user management through a client-server architecture.

## Features

* Realtime messaging
* Firebase push notifications (FCM)
* JWT authentication
* Persistent chat history with PostgreSQL
* Profile photo upload system
* Modern responsive UI
* FastAPI REST backend
* Flutter mobile frontend

## Technologies

* Flutter
* FastAPI
* PostgreSQL
* Firebase Cloud Messaging
* SQLAlchemy
* JWT Authentication
* Docker

## Architecture

The application follows a client-server architecture where Flutter acts as the mobile frontend, FastAPI handles the REST API and business logic, PostgreSQL stores persistent data and Firebase Cloud Messaging delivers realtime push notifications.

## Purpose

Sunny-Chat was developed as a full-stack mobile/backend project focused on realtime communication systems, scalable API development and modern mobile application practices.
